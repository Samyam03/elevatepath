# ElevatePath

A modern web application for building resumes, cover letters, and preparing for interviews, with AI-powered features and real-time industry insights.

[![Vercel](https://vercelbadge.vercel.app/api/Samyam03/elevatepath)](https://elevatepath.vercel.app/)
[![MIT License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

---

## 🚀 Live Demo

Access the app here: [elevatepath.vercel.app](https://elevatepath.vercel.app/)

---

## ✨ Features

- Secure user authentication (sign up & sign in)
- Create AI-optimized resumes and cover letters
- Personalized onboarding for tailored career guidance
- AI-powered interview preparation and analytics
- Real-time industry insights and salary data
- Clean, responsive dashboard and workspace
- Fast, reliable cloud deployment

---

## 🛠️ Tech Stack

- **Next.js** – React framework for SSR, routing, and API routes
- **React** – UI components and state management
- **JavaScript (JSX)** – Main programming language
- **Prisma** – Database ORM for PostgreSQL
- **Clerk** – User authentication and management
- **Inngest** – Background jobs and automation
- **Tailwind CSS** – Utility-first CSS styling
- **Vercel** – Cloud deployment and hosting

---

## 📁 Project Structure

- `app/` – Main app code (auth, dashboard, resume, cover letter, interview, onboarding, API routes)
- `components/` – Reusable UI components and data files
- `actions/` – Server-side logic for user actions
- `lib/` – Utility functions, database client, integrations
- `prisma/` – Database schema and migration files
- `public/` – Static assets (images, icons)

---

## 🧭 How It Works

1. Users sign up or sign in securely.
2. Personalized onboarding collects user industry and experience.
3. Dashboard provides access to resume, cover letter, and interview tools.
4. Users can generate AI-powered resumes and cover letters.
5. Interview prep offers quizzes and analytics to track progress.
6. Real-time industry insights and salary data are shown on the dashboard.
7. All data is managed securely with Prisma and PostgreSQL.

## 🖥️ Getting Started

### Prerequisites
- Node.js (v16+ recommended)
- npm, yarn, pnpm, or bun

### Installation

Clone the repository:
```bash
git clone https://github.com/Samyam03/elevatepath.git
cd elevatepath
```

Install dependencies:
```bash
npm install
# or
yarn install
# or
pnpm install
# or
bun install
```

Start the development server:
```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
